# Windows Endpoint Telemetry Analysis

## Project Overview

This project demonstrates how Windows Event Logs and Sysmon telemetry can be collected, organized, and analyzed using Python. The objective is to simulate a digital forensic workflow that identifies security-relevant events such as process creation, authentication activity, PowerShell execution, registry modifications, and network connections.

The project is intended for educational purposes and as a portfolio project demonstrating practical cybersecurity, digital forensics, and Python programming skills.

---

## Objectives

- Parse Windows Event Log data
- Analyze Sysmon event logs
- Detect suspicious PowerShell activity
- Identify authentication events
- Build event timelines
- Produce investigation reports
